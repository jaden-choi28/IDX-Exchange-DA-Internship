# IDX Exchange Data Analyst Internship

## Overview

This repository documents my work as a Data Analyst Intern at IDX Exchange, a real estate technology company focused on large-scale property listing and transaction data.

During this 12-week remote internship, I worked with real-world MLS-style datasets to clean, analyze, and visualize real estate market data. The primary goal was to transform raw transaction data into clear business insights using Python, Tableau, and data analysis techniques.

Company: IDX Exchange
Role: Data Analyst Intern
Location: Remote
Duration: 12 Weeks
Time Commitment: 5 to 10 hours per week

## About IDX Exchange

IDX Exchange develops real estate analytics tools and dashboards using large property listing and transaction datasets.

The company focuses on transforming real estate data into useful market insights for agents, brokerages, and other real estate professionals.

## Internship Focus

My work focused on four main areas:

* Real estate transaction data analysis
* Data cleaning and preparation
* Market trend analysis
* Dashboard development and data visualization

## Responsibilities

### Data Cleaning and Preparation

* Cleaned and structured large real estate transaction datasets
* Identified missing, inconsistent, and invalid values
* Converted columns into appropriate numeric and datetime formats
* Created calculated fields for further analysis
* Identified and handled potential outliers
* Prepared cleaned datasets for Tableau visualization

### Real Estate Market Analysis

Created and analyzed metrics such as:

* Median sale price
* Average sale price
* Price per square foot
* Listing-to-sale price ratio
* Days on market
* Listing-to-contract time
* Contract-to-close time
* Sales volume
* Number of transactions

### Geographic Analysis

Analyzed market performance across different geographic levels, including:

* County
* MLS area
* ZIP code
* Property type
* Property subtype

This allowed market performance to be compared across regions and property categories.

## Data Analysis Workflow

The general workflow used throughout the internship was:

1. Import raw transaction data
2. Inspect columns and data types
3. Clean missing or invalid values
4. Standardize data formats
5. Create calculated metrics
6. Identify and handle outliers
7. Group data by relevant market segments
8. Export cleaned datasets
9. Connect datasets to Tableau
10. Build dashboards and visualizations
11. Interpret results
12. Summarize key business insights
